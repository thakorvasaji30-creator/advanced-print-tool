📚 Useful Printing Guides

This section provides general information to help users prepare digital images and documents for printing.

📸 Passport Photo Size

A commonly used passport photograph size is 35 × 45 mm. Before printing, check the exact photo-size requirement of the organization, application or document for which the photograph will be used.

💳 Standard Card Size

A commonly used bank or ID card dimension is approximately 85.6 × 53.98 mm. Actual requirements can differ depending on the card or organization.

📄 A4 Paper Size

A4 paper measures 210 × 297 mm. Portrait orientation is normally used for documents, while landscape orientation can be useful for wider content.

🖨️ Better Print Quality

For better results, use a clear, high-resolution source image. Check the crop carefully before printing and confirm that the selected paper size and printer settings match the intended output.

✂️ Crop Before Printing

Use the crop box to select only the required area of an image. The green crop box can be moved and its four corners can be resized. Ratio lock can be used when a fixed proportion is required.

🔒 Privacy While Using Image Tools

Avoid uploading or processing sensitive documents on computers you do not trust. Always follow applicable privacy and document handling requirements when working with identity documents.
